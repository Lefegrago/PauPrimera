# Invitación web — Paula Alexa

Primera versión de la invitación para GitHub Pages.

## Archivos
- `index.html` — estructura y contenido.
- `styles.css` — diseño responsive.
- `script.js` — interacción ligera.
- `images/` — espacio para fotografías futuras.

## Publicación en GitHub Pages
1. Sube estos archivos al repositorio que alimenta `beatschill742-crypto.github.io`.
2. En GitHub: **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama principal (`main`) y la carpeta `/ (root)`.
5. Guarda y espera a que GitHub publique el sitio.

La invitación está diseñada primero para celular y contiene los dos enlaces de Google Maps proporcionados.
